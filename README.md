# math-hacks-2.0
AeroNav
An interactive program to allow easier learning of vector addition an a fun and interactive way.

# How to install
Download the release 1.0.0.
Extract the zip.
Install python on your system (Python 3.14.8)
Install pygame-ce with "pip install pygame-ce" in the command line
Run the main.py file in an IDE or through the python compiler
Enjoy!
